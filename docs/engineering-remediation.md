## Migration safety

`20261103010000_business_wide_document_sequences` is forward-only. No rollback SQL is supplied because returning to branch-local counters can recreate business-wide collisions. Before any live application, take and verify a database backup, test the upgrade on a production-like copy, review assigned numbers, then run `npm run db:deploy` in a controlled window. This work did not connect to or migrate production.
